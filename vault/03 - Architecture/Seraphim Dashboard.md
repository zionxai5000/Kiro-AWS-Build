## When to Use Dashboard vs Obsidian

| Use Dashboard When... | Use Obsidian When... |
|---|---|
| Checking live agent health | Writing strategic directives |
| Responding to escalations | Reviewing recommendations thoughtfully |
| Monitoring cost spikes | Browsing institutional knowledge |
| Watching workflow progress | Planning next initiatives |
| Real-time alerts | Offline thinking and annotating |
