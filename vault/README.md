# SeraphimOS — Obsidian Vault

This folder is your Obsidian vault. Open it in Obsidian by selecting **Open folder as vault** and pointing to this directory.

## Structure

- `00 - Command/` — Directives, recommendations, decisions
- `01 - Operations/` — Live system state, agent status, reports
- `02 - Knowledge/` — What the system has learned per domain
- `03 - Architecture/` — Specs, design docs, capability map
- `04 - Business/` — Per-pillar strategy and execution
- `05 - Audit/` — Governance trail, escalations, approvals
- `Templates/` — Note templates for directives, recommendations, etc.

## How to Use

1. Download Obsidian from https://obsidian.md (free for personal use)
2. Open this folder as a vault
3. Install recommended plugins (see `Setup.md`)
4. Start working — write directives, review recommendations, browse knowledge

## Sync

This vault lives inside the Seraphim Git repo. All changes are version-controlled.
When the system produces output (reports, recommendations, knowledge), it writes directly here.
When you write directives or approve recommendations, the system picks them up automatically.
