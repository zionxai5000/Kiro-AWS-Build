# Eretz — Business Portfolio Orchestrator

> The strategic business leader. Sits between Seraphim Core and all business subsidiaries. Every business directive passes through Eretz.

## Role

- Enriches every directive with portfolio context, applicable patterns, synergy opportunities
- Enforces chain of command (no bypassing directly to subsidiaries)
- Detects and activates cross-business synergies
- Maintains the [[Pattern Library]]
- Tracks portfolio metrics across all subsidiaries
- Issues training feedback to improve subsidiary performance

## Subsidiaries

- [[ZionX]] — App Factory
- [[ZXMG]] — Media Production
- [[Zion Alpha]] — Trading

## Key Capabilities

| Capability | Description |
|---|---|
| Directive Enrichment | Adds intelligence to every directive before forwarding |
| Synergy Detection | Finds revenue/operational opportunities across businesses |
| Pattern Library | Proven patterns extracted from one subsidiary, applied to others |
| Training Cascade | Structured feedback improving subsidiary decision quality |
| Portfolio Dashboard | Aggregated MRR, growth, unit economics across all subs |

## Standing Rules

- ZXMG videos MUST include ZionX app commercials
- Zion Alpha insights inform ZionX app ideas (market signal → app opportunity)
- All subsidiaries share performance patterns via [[Pattern Library]]

## Heartbeat Review

- Schedule: Daily
- Focus: Portfolio metrics, synergy scanning, benchmark comparison, strategic recommendations
