# Eretz Standing Orders

> Permanent rules enforced by [[Eretz]] across all business subsidiaries. These are NOT recommendations — they are mandatory.

## Active Standing Orders

### 1. Cross-Promotion (ZXMG → ZionX)

**Rule**: Every ZXMG video MUST include a ZionX app commercial.

- Applies to: ALL ZXMG video content (YouTube, TikTok, Instagram, etc.)
- Format: 5-15 second segment showing app features, download CTA
- Placement: Mid-roll or end-screen (not intro — don't lose viewers)
- Tracking: Compliance checked post-production, logged to audit

### 2. Market Intelligence Sharing (Zion Alpha → ZionX)

**Rule**: Zion Alpha market insights MUST be shared with ZionX for app opportunity identification.

- Applies to: Any market signal indicating consumer interest/demand
- Format: Structured insight note with signal, confidence, opportunity description
- Delivery: Via Event Bus, stored in ZionX's working memory
- Example: "High activity on 'AI fitness' markets → potential fitness app opportunity"

### 3. App Launch Campaigns (ZionX → ZXMG)

**Rule**: Every app that goes live MUST trigger a ZXMG content campaign.

- Applies to: Any ZionX app transitioning to `live` state
- Format: Minimum 3 pieces of content (1 long-form, 2 short-form)
- Timeline: First content within 48h of app going live
- Tracking: Campaign tracked as synergy activation

### 4. Pattern Extraction (All → Pattern Library)

**Rule**: Any subsidiary achieving measurable success MUST have the pattern extracted for cross-application.

- Applies to: Any outcome exceeding targets by >20%
- Format: Structured pattern entry in [[Pattern Library]]
- Responsible: [[Eretz]] extracts, documents, recommends to other subs
- Tracking: Pattern adoption rate per subsidiary

## Enforcement

- Eretz checks compliance as part of result verification
- Non-compliance logged to XO Audit
- Repeated non-compliance triggers remediation + training feedback
- Compliance score tracked per subsidiary
