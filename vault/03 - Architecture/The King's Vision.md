# The King's Vision

> The guiding principles that Seraphim translates into strategy.

## Core Beliefs

1. **Agents must be REAL** — Memory, tools, execution traces. Not chatbots with personality prompts.
2. **Revenue first** — The system exists to generate money. ZionX apps, ZXMG content, Zion Alpha trades.
3. **Real data only** — No mock data at any layer. If it's on the dashboard, it's live.
4. **Self-improvement is non-negotiable** — The system gets smarter every day. Zero repeat failures.
5. **Cost discipline** — Token cost DOWN, revenue UP. Intelligent routing, not brute force.

## Strategic Priorities (Current)

1. Revenue generation through ZionX app submissions
2. ZXMG content pipeline activation (autonomous production)
3. Zion Alpha trading execution (prediction markets)
4. System self-improvement (Learning Engine)
5. Token cost optimization (Model Router)

## Autonomy Expectations

- The King provides **vision** — not micromanagement
- Seraphim formulates **strategy** from vision
- Agents **execute** strategy autonomously
- The King reviews **outcomes** and adjusts vision
- Interventions should decrease over time as the system matures

## North Star Metrics

- **Capability Maturity Score**: Progress toward fully autonomous operation
- **Monthly Revenue**: Combined across all pillars
- **Autonomous Resolution Rate**: % of problems resolved without King involvement
- **Token Cost per Dollar Revenue**: Efficiency of LLM spend
- **Mean Time to Revenue**: How fast a new initiative generates income
